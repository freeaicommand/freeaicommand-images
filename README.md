# freeaicommand-images

Result photos for freeaicommand.com prompts, served via the jsDelivr CDN.

## Credit

Every image here belongs to its creator. On freeaicommand.com each photo is shown with a credit and a link to the creator's original Instagram or Threads post.

## Removal requests

If you are the creator or owner of an image in this repo and would like it removed, email support@freeaicommand.com with the image filename or the page it appears on, and it will be removed promptly.
